Image AES Encryption System

This module extends AES encryption to image files by converting image files into raw binary data instead of hex strings and encrypting them using a custom AES-256 implementation written in C++.

Core Features

  • Single Image Encryption & Decryption
  • Multiple Images processing along with showing number of images selected
  • ZIP File Handling for Encrypted/Decrypted Files

Input/Output Format

  • Encrypted Image files → .enc
  • Decrypted Image files → original image format (.png or .jpg)
  • Both Encrypt and Decrypt operations create downloadable ZIP Files.

How Image Encryption Works

  1. Image file is read as raw binary data (not text).
  2. Data is split into 16-byte AES blocks.
  3. AES-256 encryption is applied to each block.
  4. Encrypted binary is saved as .enc file.
  5. For decryption, the process is reversed to restore the image.

Technical Workflow

  • Flask handles file upload and temporary storage
  • C++ AES engine processes encryption/decryption
  • Binary-safe file handling (no UTF-8 conversion)
  • Temporary files are cleaned after processing
