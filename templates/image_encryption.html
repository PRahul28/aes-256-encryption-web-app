Image AES Encryption System

This module extends AES encryption to images by converting image files into raw binary data and encrypting them using a custom AES-256 implementation written in C++.

How Image Encryption Works

  1. Image file is read as raw binary data (not text).
  2. Data is split into 16-byte AES blocks.
  3. AES-256 encryption is applied to each block.
  4. Encrypted binary is saved as .enc file.
  5. For decryption, the process is reversed to restore the image.

Supported Features

  • Single image encryption & decryption
  • Batch multiple image processing
  • ZIP output for encrypted/decrypted files
  • Secure AES-256 key-based encryption

Technical Workflow

  • Flask handles file upload and temporary storage
  • C++ AES engine processes encryption/decryption
  • Binary-safe file handling (no UTF-8 conversion)
  • Temporary files are cleaned after processing

Important Note

Images are treated as binary streams, not text. This ensures lossless encryption and accurate restoration after decryption.

Output Format

  • Encrypted files → .enc
  • Decrypted files → original image format (.png, .jpg, etc.)
  • Batch operations → downloadable ZIP archive
