About AES-256 Encryption

Rijndael Algorithm is selected as the AES (Advanced Encryption Standard) which is a symmetric-key encryption algorithm used worldwide to secure sensitive data.

Implementation

This project uses a custom AES-256 implementation written in C++. Using the original research paper by Joan Daemen and Vincent Rijmen, the Core AES operations like SubBytes, ShiftRows, MixColumns, AddRoundKey, Key Expansion, Encryption and Decryption are implemented manually and integrated with a Flask-based web interface.

Key Features

  • AES-256 uses a 256-bit key (32 characters in this project).
  • AES operates on fixed 128-bit data blocks.
  • AES-256 performs 14 rounds of transformation on every block.
  • Each round increases resistance against cryptographic attacks.
  • The same key is required for successful decryption.

AES Encryption Process

  1. Convert plaintext into 128-bit blocks.
  2. Expand the 256-bit key into round keys using Key Expansion.
  3. Initial AddRoundKey operation.
  4. 13 rounds consisting of:
    • SubBytes
    • ShiftRows
    • MixColumns
    • AddRoundKey

  5. Final Round:
    • SubBytes
    • ShiftRows
    • AddRoundKey

  6. Encrypted text is produced.

How This Project Works

  • User provides a 32-character AES key.
  • Text can be entered manually or uploaded through a file.
  • The Flask backend communicates with a C++ AES implementation.
  • Encryption and decryption are performed by the AES engine.
  • Results can be copied directly or downloaded as files.
